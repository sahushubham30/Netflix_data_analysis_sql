# 📺 Netflix SQL Data Analysis Project

A comprehensive SQL data analysis project built using the Netflix Movies & TV Shows dataset. This project demonstrates proficiency in SQL querying, data exploration, aggregation, window functions, string manipulation, date handling, and analytical problem-solving using PostgreSQL.



---

## 📌 Project Overview

The objective of this project is to analyze Netflix's content library and extract meaningful business insights using SQL.

The project covers real-world analytical questions that are commonly asked in Data Analyst and Business Analyst interviews while applying advanced SQL concepts.

---

## 🛠 Tech Stack

- **Database:** PostgreSQL
- **Language:** SQL
- **Dataset:** Netflix Movies & TV Shows Dataset (CSV)

---

## 📂 Database Schema

The dataset contains information such as:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

---

# 📊 Business Problems Solved

This project answers practical business questions including:

1. Count Movies vs TV Shows
2. Find the most common rating for each content type
3. List movies released in a specific year
4. Identify the top countries producing Netflix content
5. Find the longest movie available
6. Retrieve content added in the last five years
7. Search content by a specific director
8. Find TV Shows with more than five seasons
9. Count content across different genres
10. Analyze yearly content trends by country
11. (Additional analysis can be added as the project grows)
